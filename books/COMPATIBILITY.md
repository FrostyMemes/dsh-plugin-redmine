## Redmine

Сервер недоступен, точный релиз и права неизвестны. Годы 2022–2023 обозначают возраст установки/обновления, а не гарантированную версию API.

Реализация использует базовые GET endpoints: `users/current.json`, `projects.json`, `issues.json`, `issue_statuses.json`, `enumerations/issue_priorities.json` и детали проекта с `include=trackers,issue_categories`. Общий `trackers.json` не вызывается: типы задач собираются из деталей доступных проектов. Отдельный endpoint категорий заменён согласно списку маршрутов инстанса, предоставленному пользователем; [карта endpoints и границы использования](REDMINE_ENDPOINTS.md). Не предполагаются современные endpoint health/version либо расширенные фильтры. Пользователь текущего API нормализуется из `firstname/lastname/login`; названия словарей читаются с сервера.

Форматы тестовых ответов и границы базового поведения сверены с [Users API](https://www.redmine.org/projects/redmine/wiki/Rest_Users) и [Issues API](https://www.redmine.org/projects/redmine/wiki/Rest_Issues). Эти документы не заменяют проверку корпоративной установки.

При появлении доступа пользователь проверяет подключение через настройки и реальные права/справочники. Плагин показывает частичные ограничения и не подменяет их mock-результатами.

## Ограничения

- Новые версии DSH не заявлены совместимыми: manifest фиксирует проверенный целевой SDK.
- Поиск/сложные фильтры могут требовать загрузки метаданных нескольких страниц на Host. Предел — 10 000 задач с явной индикацией неполноты.
- Запуск сессии может принять промпт, но дальнейшее выполнение агента зависит от модели, учётных данных и разрешений DSH.
- Runtime-журнал фильтрует нативные записи по Redmine. Ошибки загрузки, препятствующие активации Bundle, остаются в штатной диагностике DSH.

## Исправления 0.1.2 — 26.10.2026

- Установленный `dsh-client-ui-layout/lib/client.js` подтверждает: main slot является непосредственным ребёнком flex-колонки с `overflow:hidden`. Плагин получил собственный ограниченный по высоте scroll-root; строка возврата больше не использует `min-height:100%`. Максимальная ширина настроек 920px удалена. Внешний вид этих изменений не проверялся браузером.
- Единый редактор шаблонов сохраняет по имени, сохраняет ID при перезаписи и оставляет default-отметку черновой до сохранения. Статусы используют общую модель «все/конкретные» без потери старого начального фильтра открытых задач.
- По установленным runtime и официальным rc.3 типам подтверждено поле `SessionSummary.sessionId`; прежняя проверка `id` всегда ошибочно возвращала отсутствие сессии. Адаптер использует официальный `SessionListValue`.
- Для назначения названия используется нативный `sessionController.rename`; DSH нормализует/ограничивает title и фиксирует пользовательское название. Снимок имени и `titleApplied` сохраняются в стадии запуска до отправки промпта.
- Финальная сборка TypeScript и клиентского Bundle успешна. Выполнены целевые проверки прямым запуском test-модулей: 13 core и 2 adapter, включая поиск существующей сессии, архивирование, передачу названия и повторы после ошибок. Обычный test-runner и esbuild требовали разрешения на запуск дочерних процессов из-за sandbox `spawn EPERM`; финальная сборка выполнена с этим разрешением.
- Независимое финальное ревью исходников не оставило actionable замечаний. Браузерный/Desktop/corporate Redmine end-to-end прогон не выполнялся; поведение UI проверяет пользователь.

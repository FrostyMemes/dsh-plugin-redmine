# Изменения

## 0.1.5 — 26.10.2026

- Запросы и поля ответов сверены с исходниками Redmine `4.1-stable`; добавлены целевые проверки формата 4.1, пагинации и получения статусов без новых полей API.
- Категории загружаются и проверяются через детали проекта с `include=issue_categories`, согласно предоставленным маршрутам корпоративного инстанса.
- Неподтверждённый общий endpoint типов задач заменён сбором типов из деталей доступных проектов.
- Добавлена карта известных endpoints с границами использования панелью MVP.

## 0.1.4 — 26.10.2026

- Список переменных шаблона перенесён в подсказку у значка ⓘ с пояснением каждой вставки, поддержкой наведения и клавиатурного фокуса.

## 0.1.3 — 26.10.2026

- Кнопка «Создать шаблон» готовит несохранённый черновик с начальными значениями «Новый шаблон» / «Новый промпт», без отметки по умолчанию.
- Совпадение названия требует явного подтверждения перезаписи. Отмена не меняет сохранённые шаблоны.
- Новый пункт в списке появляется только после успешного сохранения; в коллекции сохраняется ровно один шаблон по умолчанию.

## 0.1.2 — 26.10.2026

- Исправлены высота страницы настроек из вкладки Redmine, вертикальная прокрутка и ограничение ширины настроек.
- Единый редактор шаблонов с выбором сохранённого шаблона и сохранением по названию.
- Сообщения сохранения разделены по блокам подключения, режимов и шаблона.
- Кнопка открытия логов оформлена подчёркнутым текстом.
- Статусы выбираются единым мультиселектором без отдельного блока групп.
- Новые сессии получают название задачи перед отправкой промпта; этап назначения названия сохраняется для восстановления.
- Исправлена проверка доступности созданных сессий: используется `sessionId` из ответа DSH.

## 0.1.1 — 26.10.2026

- Сценарии демонстрации перенесены на главную вкладку Redmine: видны при включённых моках и режиме разработчика, сохраняются и применяются сразу.
- Переключатели режимов сохраняются автоматически. Кнопка «Сохранить режимы» удалена.
- Просмотр логов доступен на главной вкладке в режиме разработчика как для моков, так и для настоящего API.
- Проверка подключения и результаты объединены в блоке подключения настроек. Проверка сохранённых реквизитов отделена от их сохранения.

## 0.1.0 — 25.10.2026

- Исходная реализация MVP с mock-провайдером, читающим REST API, workspace/сессиями DSH и диагностикой.
